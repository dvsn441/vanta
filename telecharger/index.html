Prêt en une minute.

Un installeur classique sur l'ordinateur. Le téléphone n'installe rien : il scanne le QR code et tape un code. Wi-Fi, 4G ou 5G : il n'a pas besoin d'être sur le même réseau que l'ordinateur.

1

Lance Thumbpad sur ton PC

Télécharge l'installeur, clique sur Suivant puis Terminer. Thumbpad se lancera désormais avec l'ordinateur et affiche un QR code à scanner avec ton téléphone.

2

Scanne le QR code

Scanne le QR code de la fenêtre Thumbpad avec l'appareil photo, ou reçois le lien par mail. Puis Partager → Sur l'écran d'accueil : Thumbpad y devient une icône.

3

Tape le code affiché

Un code à six chiffres apparaît en haut à gauche de l'écran du PC. Tape-le sur ton téléphone : c'est connecté. Et c'est réglé pour de bon : Thumbpad tourne en fond, même fenêtre fermée. La prochaine fois, touche l'icône, tape le code, pilote.

Tout ce qu'il faut. Rien de plus.

Un écran unique : la surface tactile en haut, le clavier juste en dessous.

Pavé tactile

Un doigt déplace le curseur. Toucher pour cliquer, deux doigts pour le clic droit, glisser à deux doigts pour défiler.

Clavier

Le clavier du téléphone écrit sur le PC. Échap, Tab, copier, coller et les flèches sont à portée de pouce.

Sécurité

Un nouveau code à chaque connexion. Seul celui qui voit l'écran du PC peut le piloter.

Plusieurs PC

Bureau, portable, salon. Le code que tu tapes choisit l'ordinateur à piloter.

Discret

Se lance avec l'ordinateur. Reste en arrière-plan, sans fenêtre qui traîne.

Liaison directe

Le téléphone parle au PC en direct. Même Wi-Fi ou 4G : dès que c'est possible, plus aucun serveur au milieu. Le curseur suit le doigt.

Reconnexion

Quitte l'appli, reviens. Tant que tu n'es pas parti plus de 5 minutes, pas besoin de nouveau code.

Installer pas à pas.

Windows pose deux questions au premier lancement, parce que Thumbpad est un nouveau programme. Voici quoi répondre.

Windows 10 · 11

  1. Clique sur Télécharger pour Windows. Si Chrome affiche un avertissement en bas ou en haut à droite, choisis Conserver.
  2. Double-clique sur Thumbpad-Setup.exe dans tes téléchargements, puis Suivant et Terminer. Pas besoin d'être administrateur.
  3. Si « Windows a protégé votre ordinateur » s'affiche : Informations complémentaires, puis Exécuter quand même.
  4. Dans la fenêtre du pare-feu, clique sur Autoriser. Sans ça, le téléphone ne peut pas se connecter.
  5. La fenêtre Thumbpad affiche un QR code : scanne-le avec l'appareil photo du téléphone.

Mac macOS 12+

  1. Télécharge Thumbpad pour Mac à puce Apple (M1 à M4, depuis fin 2020) ou pour Mac Intel. Pour savoir : menu → À propos de ce Mac.
  2. Ouvre le fichier .dmg et glisse l'icône Thumbpad sur le dossier Applications, juste à côté.
  3. Double-clique sur Thumbpad. Si le Mac dit qu'il ne peut pas vérifier l'appli, clique sur OK, va dans Réglages système → Confidentialité et sécurité, descends et clique sur Ouvrir quand même.
  4. Si le Mac demande d'autoriser Thumbpad à trouver des appareils sur le réseau local, clique sur Autoriser. La fenêtre Thumbpad s'affiche alors avec son QR code.
  5. Quand le Mac le demande, active Thumbpad dans Réglages système → Confidentialité et sécurité → Accessibilité. C'est ce qui lui permet de bouger la souris et de taper.

Questions.

Ce qu'on demande le plus souvent.

Pourquoi le Mac ou Windows m'avertit ?

Thumbpad est un prototype qui n'est pas encore signé par Apple ni par Microsoft. Les deux systèmes avertissent donc au premier lancement. Suis les étapes ci-dessus une seule fois, et Thumbpad s'ouvre ensuite normalement.

Le téléphone n'arrive pas à se connecter.

Regarde sous le QR code de la fenêtre Thumbpad : « INTERNET : PRÊT » doit s'afficher. Sinon, l'ordinateur n'a pas internet ou son Wi-Fi bloque Thumbpad : mets le téléphone sur le même Wi-Fi que l'ordinateur et ouvre l'adresse indiquée en bas de la fenêtre, après avoir cliqué sur Autoriser dans la fenêtre du pare-feu. Si tu l'as refusée, rouvre Thumbpad depuis le menu Démarrer : Windows la reposera, ou autorise Thumbpad dans Pare-feu Windows → Autoriser une application.

Après un redémarrage, l'appli reste noire.

Thumbpad se relance tout seul avec l'ordinateur, mais il lui faut quelques secondes une fois Windows ouvert. Attends que le bureau soit affiché, puis rouvre l'appli. Si ça ne vient toujours pas, ouvre Thumbpad depuis le menu Démarrer : il se relance et tout revient.

Où retrouver le QR code ou l'adresse ?

Tape « Thumbpad » dans le menu Démarrer (ou ouvre-le depuis Applications sur Mac) : s'il tourne déjà, sa fenêtre se rouvre avec le QR code.

Faut-il installer quelque chose sur le téléphone ?

Non. Thumbpad s'ouvre dans Safari ou Chrome, à l'adresse affichée par l'ordinateur. L'ajouter à l'écran d'accueil en fait une icône, comme une appli, sans rien télécharger.

Est-ce que ça marche hors de chez moi ?

Oui. Le téléphone peut être en 4G/5G ou sur un autre Wi-Fi : Thumbpad établit une liaison directe chiffrée avec l'ordinateur, et passe par un relais internet chiffré avec la clé du QR code quand le réseau ne le permet pas. Il faut juste que l'ordinateur et le téléphone aient internet.

Quelqu'un d'autre peut-il prendre le contrôle de mon PC ?

Il lui faudrait le code affiché sur ton écran, qui change à chaque connexion et expire au bout de trois minutes. Après cinq erreurs, le code est annulé.

Comment arrêter ou désinstaller Thumbpad ?

Ouvre la fenêtre Thumbpad et choisis Quitter Thumbpad. Pour le retirer complètement : Paramètres Windows → Applications → Thumbpad → Désinstaller, ou le lien Désinstaller de la fenêtre. Sur Mac, glisse Thumbpad d'Applications vers la Corbeille.
