Prêt en une minute.

Tout est dans Vanta.exe. Le téléphone n'installe rien : il scanne le QR code et tape un code. Wi-Fi, 4G ou 5G : il n'a pas besoin d'être sur le même réseau que l'ordinateur.

1

Lance Vanta sur ton PC

Télécharge Vanta.exe et double-clique dessus. Vanta s'installe tout seul, se lancera désormais avec l'ordinateur, et affiche un QR code à scanner avec ton téléphone.

2

Scanne le QR code

Scanne le QR code de la fenêtre Vanta avec l'appareil photo, ou reçois le lien par mail. Puis Partager → Sur l'écran d'accueil : Vanta y devient une icône.

3

Tape le code affiché

Un code à six chiffres apparaît en haut à gauche de l'écran du PC. Tape-le sur ton téléphone : c'est connecté. Et c'est réglé pour de bon : Vanta tourne en fond, même fenêtre fermée. La prochaine fois, touche l'icône, tape le code, pilote.

Tout ce qu'il faut. Rien de plus.

Un écran unique : la surface tactile en haut, le clavier juste en dessous.

Pavé tactile

Un doigt déplace le curseur. Toucher pour cliquer, deux doigts pour le clic droit, glisser à deux doigts pour défiler.

Clavier

Le clavier du téléphone écrit sur le PC. Échap, Tab, copier, coller et les flèches sont à portée de pouce.

Sécurité

Un nouveau code à chaque connexion. Seul celui qui voit l'écran du PC peut le piloter.

Plusieurs PC

Bureau, portable, salon. Le code que tu tapes choisit l'ordinateur à piloter.

Discret

Se lance avec l'ordinateur. Reste en arrière-plan, sans fenêtre qui traîne.

Reconnexion

Quitte l'appli, reviens. Tant que tu n'es pas parti plus de 5 minutes, pas besoin de nouveau code.

Installer pas à pas.

Windows pose deux questions au premier lancement, parce que Vanta est un nouveau programme. Voici quoi répondre.

Windows 10 · 11

  1. Clique sur Télécharger pour Windows. Si Chrome affiche un avertissement en bas ou en haut à droite, choisis Conserver.
  2. Double-clique sur Vanta.exe dans tes téléchargements.
  3. Si « Windows a protégé votre ordinateur » s'affiche : Informations complémentaires, puis Exécuter quand même.
  4. Dans la fenêtre du pare-feu, clique sur Autoriser. Sans ça, le téléphone ne peut pas se connecter.
  5. La fenêtre Vanta affiche ton adresse : ouvre-la sur ton téléphone.

Mac macOS 12+

  1. Télécharge Vanta pour Mac à puce Apple (M1 à M4, depuis fin 2020) ou pour Mac Intel. Pour savoir : menu → À propos de ce Mac.
  2. Ouvre le fichier .dmg et glisse Vanta dans Applications.
  3. Double-clique sur Vanta. Si le Mac dit qu'il ne peut pas vérifier l'appli, clique sur OK, va dans Réglages système → Confidentialité et sécurité, descends et clique sur Ouvrir quand même.
  4. Si le Mac demande d'autoriser Vanta à trouver des appareils sur le réseau local, clique sur Autoriser. La fenêtre Vanta s'affiche alors avec son QR code.
  5. Quand le Mac le demande, active Vanta dans Réglages système → Confidentialité et sécurité → Accessibilité. C'est ce qui lui permet de bouger la souris et de taper.

Questions.

Ce qu'on demande le plus souvent.

Pourquoi le Mac ou Windows m'avertit ?

Vanta est un prototype qui n'est pas encore signé par Apple ni par Microsoft. Les deux systèmes avertissent donc au premier lancement. Suis les étapes ci-dessus une seule fois, et Vanta s'ouvre ensuite normalement.

Le téléphone n'arrive pas à se connecter.

Regarde sous le QR code de la fenêtre Vanta : « INTERNET : PRÊT » doit s'afficher. Sinon, l'ordinateur n'a pas internet ou son Wi-Fi bloque Vanta : mets le téléphone sur le même Wi-Fi que l'ordinateur et ouvre l'adresse indiquée en bas de la fenêtre, après avoir cliqué sur Autoriser dans la fenêtre du pare-feu. Si tu l'as refusée, relance Vanta.exe : Windows la reposera, ou autorise Vanta dans Pare-feu Windows → Autoriser une application.

Après un redémarrage, l'appli reste noire.

Vanta se relance tout seul avec l'ordinateur, mais il lui faut quelques secondes une fois Windows ouvert. Attends que le bureau soit affiché, puis rouvre l'appli. Si ça ne vient toujours pas, double-clique une fois sur Vanta.exe : il se relance et tout revient.

Où retrouver le QR code ou l'adresse ?

Double-clique à nouveau sur Vanta.exe : s'il tourne déjà, sa fenêtre se rouvre avec l'adresse.

Faut-il installer quelque chose sur le téléphone ?

Non. Vanta s'ouvre dans Safari ou Chrome, à l'adresse affichée par l'ordinateur. L'ajouter à l'écran d'accueil en fait une icône, comme une appli, sans rien télécharger.

Est-ce que ça marche hors de chez moi ?

Oui. Le téléphone peut être en 4G/5G ou sur un autre Wi-Fi : Vanta passe alors par internet, chiffré de bout en bout avec la clé du QR code. Il faut juste que l'ordinateur et le téléphone aient internet.

Quelqu'un d'autre peut-il prendre le contrôle de mon PC ?

Il lui faudrait le code affiché sur ton écran, qui change à chaque connexion et expire au bout de trois minutes. Après cinq erreurs, le code est annulé.

Comment arrêter ou désinstaller Vanta ?

Ouvre la fenêtre Vanta (double-clic sur Vanta.exe) et choisis Quitter Vanta. Pour le retirer complètement, choisis Désinstaller dans la même fenêtre, puis supprime le fichier Vanta.exe.
